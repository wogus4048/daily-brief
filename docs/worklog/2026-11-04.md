## 이어서 할 일

1. 브랜치를 받는다.

   ```bash
   git fetch origin
   git switch fix/crawler-resilience
   npm install
   ```

2. DACON 검토 대상 0건을 확인한다. `scripts/actionability.mjs`와 실제 카드 문구를 비교한다. 로컬 크롤러 실행으로 `data/source-cache/`에 생긴 시험 결과는 커밋하지 않는다.

   ```bash
   npx playwright install chromium
   node scripts/crawl_sources.mjs
   ```

3. 전체 테스트를 실행한다.

   ```bash
   npm test
   ```

4. 독립 리뷰 후 `main`에 합친다. `crawl-sources.yml`은 항상 `main`을 체크아웃하므로 러너 검증은 합친 뒤에만 가능하다.
5. 크롤링을 켜고 한 번 실행해 러너에서 DACON이 수집되는지 본다. 사용자가 재개를 원하지 않으면 끝난 뒤 다시 끈다.

   ```bash
   gh workflow enable crawl-sources.yml
   gh workflow run crawl-sources.yml --ref main
   ```

   ```bash
   gh workflow disable crawl-sources.yml
   ```

6. 상태 점검은 ChatGPT 예약 재개와 함께 켠다. 발행이 멈춘 채 켜면 매일 실패 메일이 온다.
7. `docs/chatgpt-task-prompt.txt`와 예약 재개 여부는 사용자가 결정한다.
